# Kala Sangam - Traditional Arts Platform

**WEB WONDERS**  
**Team – WEB MINDS**

Kala Sangam is a digital platform dedicated to celebrating and preserving India's traditional arts.  
It connects artists, enthusiasts, and cultural explorers through an interactive, community-driven experience.

---

## Overview
- Artist Profiles – Showcase skills and portfolio
- Art Gallery – Upload and browse traditional artworks
- Interactive India Map – Explore arts by states and regions
- Event Listings – Discover cultural events and workshops
- Secure User Management – JWT authentication, profile customization, follow system

---

## Tech Stack

**Frontend**
- React 18 + Vite  
- Tailwind CSS (custom Indian-inspired themes)  
- React Router DOM  
- Framer Motion, AOS, GSAP (animations)  
- SVG India Map  

**Backend**
- Node.js + Express  
- MongoDB with Mongoose ODM  
- JWT authentication with bcrypt hashing  
- Express Validator, CORS  
- Nodemailer for email notifications  

---

## Installation

### Prerequisites
- Node.js 18+
- MongoDB
- npm or yarn

### Steps
1. Clone Repository
```bash
git clone https://github.com/NainaJain-AI/TRADITIONAL-ARTS.git
cd TRADITIONAL-ARTS
```
2.Install Root Dependencies
```bash
npm install
# or
yarn install
```
3. Navigate to the Frontend Directory and Install Dependencies
```bash
cd client
npm install
# or
yarn install
```
4.Navigate to the Backend Directory and Install Dependencies
```bash
cd ../server
npm install
# or
yarn install
```
5. Run the Development Servers
.Backend
```bash
npm run dev
```
.Frontend
```bash
cd client
npm run dev
```
6.Open the App
Visit http://localhost:5173 in your browser.
